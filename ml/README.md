# ML Module

## Files
- `preprocessing.py` - PreprocessingPipeline class
- `features.py` - Feature definitions and constants
- `train.py` - Training script
- `evaluate.py` - Evaluation functions
- `predict.py` - predict_yield() interface

## Quick Start
```bash
cd ml
python train.py
```

## Artifacts
After training, these files are created (NOT in Git):
- `model/crop_yield_model.joblib`
- `model/preprocessor.joblib`
